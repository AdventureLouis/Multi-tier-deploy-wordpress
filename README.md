
Designed and deployed a highly available multi-tier WordPress architecture on AWS using Infrastructure as Code (Terraform).
Technologies & AWS Services Used

* AWS VPC
* EC2
* Bastion Host
* Application Load Balancer
* Amazon RDS MySQL
* Route 53
* IAM
* AWS Secrets Manager
* Terraform

Key Features

* Automated infrastructure provisioning with Terraform
* Secure network architecture using private/public subnets
* Bastion host for secure administrative access
* High availability using Load Balancer
* Managed MySQL database with Amazon RDS
* Secure credential management using AWS Secrets Manager
* Automated domain and DNS configuration with Route 53

Outcome

This project strengthened my hands-on experience with:

* Infrastructure as Code (IaC)
* AWS cloud architecture
* Terraform automation
* Secure and scalable deployments
* Production-style DevOps workflows
